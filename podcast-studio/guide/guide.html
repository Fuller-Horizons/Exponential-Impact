What goes in, what comes out

Inputs and outputs

You give it

  • A topicOne or two sentences about what the video should say.
  • Length and shapeSeconds (45 by default) and 9:16, 16:9 or 1:1.
  • A voice sample8 to 15 seconds of clean speech, cut from an episode in the Voice clone tab.
  • Your episodesA folder of episode videos, indexed once so the app can search what was said.
  • FramingHow hosts appear: Auto, Stacked, Side by side, Both in frame, One person, Left person, Right person, or Active speaker (cuts to whoever is talking).
  • Style bible optionalBuilt from your episodes. Steers hooks, tone and pacing.
  • Brand kit optionalColours, font, caption highlight and a corner logo.
→

You get back

  • final.mp4The finished video with burned-in captions and normalised sound.
  • outline.txtThe outline you approved, plus three hook options in hooks.json.
  • script.jsonEvery scene: narration, scene type and the footage it uses.
  • captions.assWord-by-word caption timing.
  • qa.jsonThe quality report: pass, warning or fail for each check.
  • metrics.jsonTime per stage and peak graphics memory.

All in PodcastStudio\workspace\projects\<project name>\

Inside one run

How a video gets made

Six stages run in order. Each one saves its work, so a run that stops can pick up where it left off.

  1. STAGE 1

    Outline

    A language model on your PC drafts a title, three hooks, the beats and a closing line. You pick a hook, edit freely, then approve.

    Uses Ollama (local model)Saves outline.txt, hooks.json
  2. STAGE 2

    Script and shot list

    The outline becomes spoken narration split into scenes. Each scene is given a type and, for footage, a real moment from your episodes.

    Uses Ollama + footage searchSaves script.json
  3. STAGE 3

    Voice

    Each narrated scene is spoken in your cloned voice. The app listens back to every line and re-makes any that came out garbled.

    Uses Qwen3-TTS on the GPUSaves voice\scene_01.wav …
  4. STAGE 4

    Visuals

    One clip per scene, cut to the exact length of its voice line. Footage is cropped around the speaker's face.

    Uses ffmpeg, face detectionSaves visuals\scene_01.mp4 …
  5. STAGE 5

    Render

    Scenes are joined. Captions highlight each word as it is spoken, loudness is set to −14 LUFS, and the logo is added.

    Uses ffmpeg on the CPUSaves final.mp4, captions.ass
  6. STAGE 6

    Quality gate

    Checks length, resolution, loudness, black frames, long silences, caption coverage, and that the voice matches the script.

    Uses ffmpeg, speech-to-textSaves qa.json
What you see on screen

Four kinds of scene

Soundbite

A real clip of the hosts, played with its own sound. Up to two per video.

Footage

Silent episode footage under the narration, framed the way you choose: stacked, side by side, both in frame, or one person.

Card

Bold text on screen in your brand colours, with a slow zoom.

Still optional

A generated image with a slow zoom. Off unless you tick AI stills.

Once, after installing

Set up the studio

  1. Open Podcast Studio from the desktop shortcut.
  2. Voice clone tab: paste an episode link or press Browse..., set Start (MM:SS) and 8 to 15 Seconds, then press Extract sample. Press Play sample to check it.
  3. Create tab: next to Episode folder press Browse..., choose the folder of episode videos, then press Index footage.
  4. Analyze tab: press Build style bible (local).
  5. Create tab: press Brand kit..., set colours, font, logo and music bed, then Save.
  6. Analyze tab: press Compare local models. The best one becomes the default.
  7. Create tab: press Full self-test and keep logs\selftest.json.
  8. Press Save as profile defaults at the top so every new video starts with this setup.

Indexing transcribes every episode, so it takes a few minutes per 45-minute episode. You only repeat it when you add episodes.

Create tab

Make a video from a topic

  1. Fill in Project name, Length (s), Format and Framing.
  2. Type what the video is about in Video topic / prompt.
  3. Check that Voice sample WAV points to your voice sample.
  4. Press 1. Draft outline and wait for the outline to appear.
  5. Choose an opening line in Hook (pick one), then edit the outline as you like.
  6. Tick or untick Soundbites, AI stills and Lip-sync.
  7. Press 2. Approve + make video. When it finishes, the folder opens on final.mp4.
  8. Scenes tab: press Quality report and read any warnings.

If a stage fails, press 2. Approve + make video again. Finished work is kept.

Scenes tab

Fix one scene

  1. Make sure the Create tab shows the right Project name.
  2. Press Load scenes and click the scene in the list.
  3. Change Type, Framing, Narration, Search words or Card text.
  4. Press Save scene.
  5. Press Apply changes + re-make video. Only what you changed is rebuilt.
  6. Press Play video to check the result.

Re-make this scene gives a new voice take and the next best footage without editing anything. Add after and Delete add or remove a scene.

Highlights tab

Turn an episode into clips

  1. The episode must already be in the footage index (see Set up the studio).
  2. Next to Episode video press Browse... and choose the episode file.
  3. Set Clips to make, Shortest (s), Longest (s) and Shape.
  4. Leave Framing on Active speaker to cut to whoever is talking. Untick Headline if you don't want a title on screen.
  5. Press Find highlights + make clips.
  6. Click a row and press Play selected, or press Open clips folder.

Clips use the hosts' own voices. Nothing is narrated or cloned.

Edit recording tab · hybrid

Edit a raw recording with Claude Code

  1. Next to Raw recording press Browse... and choose your take. Project name fills in.
  2. Set Type to Short (reel or Short) or Long video. Leave Remove pauses here first ticked.
  3. Press 1. Prepare (transcribe here). Your PC copies and transcribes the recording and removes the pauses.
  4. Read the box labelled What Claude Code will be asked and change it if you want.
  5. Leave Editor on Claude Code and press 2. Edit with the editor. A new window opens.
  6. In that window, answer Claude's questions and approve the planned cuts before it renders.
  7. Give notes in plain words. Ask it to save a note as a house rule to make it permanent.
  8. Press Open project folder and look in renders for the finished video.

Claude Code is a cloud model and uses your Claude subscription. The transcript and editing decisions go to Claude; the video files stay on your PC. Run claude once in PowerShell to sign in.

Edit recording tab · hybrid

Edit a long recording (over about 15 minutes)

  1. Next to Raw recording press Browse... and choose the recording. Project name fills in, for example my-talk.
  2. Set the length of each part in the box after parts of (8 minutes is a good start).
  3. Press Split long recording. It cuts at natural pauses and makes my-talk-part-01, -02 and so on.
  4. Change Project name to my-talk-part-01 and press 2. Edit with the editor. Finish that part in the editor's window.
  5. Repeat for each part.
  6. Change Project name back to my-talk and press Join edited parts. The folder opens on my-talk-joined.mp4.

Each part is edited and rendered on its own, so memory stays low on a 16 GB PC. Parts that have not been rendered yet are named if you join too early.

Edit recording tab

Trim dead air, no AI

  1. Next to Raw recording press Browse... and choose your take.
  2. Press Quick trim (no AI).
  3. The folder opens on a new file ending in .tight.mp4, saved next to the original.

It only shortens pauses longer than about half a second, and it works one piece at a time, so even an hour-long recording stays within memory. Your original file is not changed.

Publish tab

Write social posts

  1. Make sure the Create tab shows the Project name of a finished video.
  2. Press Write social posts (local).
  3. The social folder opens with linkedin.txt, x-thread.txt, carousel.txt and the slide images.
  4. To sharpen them, press Polish with Claude Code and review its changes.
  5. Copy the text and upload the slides to each platform yourself.

These are drafts. The app never posts to LinkedIn, X or Instagram.

Publish tab

Publish to YouTube

  1. First time only: in Google Cloud Console create a project, enable YouTube Data API v3, create an OAuth client of type Desktop app and download its JSON file.
  2. First time only: press YouTube sign-in file... and choose that file.
  3. Press Load, then Write title + description (local).
  4. Edit Title, Description and Tags (commas).
  5. Choose Privacy. To schedule, keep it private and type a time in Schedule, like 2026-12-01 09:30.
  6. Press Save, then Upload to YouTube, and confirm.
  7. The first upload opens your browser to sign in. Press Open to see the video afterwards.

Uploads are private unless you change Privacy. The sign-in is remembered in workspace\youtube_token.json; treat that file like a password.

Analyze tab

Import your videos from YouTube

  1. Paste a video, playlist or channel link in YouTube URL or file.
  2. Set how many videos to take in the up to box.
  3. Press Download + index (YouTube).
  4. The videos land in workspace\episodes and are added to the footage index.

Only for videos you own or have permission to reuse.

Voice clone tab

Make a voiceover only

  1. Check that Reference WAV points to your voice sample.
  2. Type or paste the words in Script to speak.
  3. Choose Language and leave Device on cuda.
  4. Press Generate voiceover, then Play last voiceover.

The file is saved in workspace\output. Only clone voices of people who have agreed.

Assemble tab

Join clips by hand

  1. Press Add... and choose your clips. Use Move up and Move down to order them.
  2. Optional: choose a Voiceover and a Music file.
  3. Choose Format and tick Burn in captions if you want them.
  4. Press Render MP4, then Play last render.

The result is saved in workspace\output.

Scenes tab · Edit recording tab

Make a correction stick

  1. Scenes tab: press Add a house rule....
  2. Type the correction as one sentence, for example "Never open with a greeting."
  3. Press Save rule.
  4. To review or delete rules, go to Edit recording and press House rules.

Every later script, edit and social post follows these rules.

Profile bar · top of the window

Set up a show or persona once, reuse it forever

  1. Press New... next to Profile, type the show's name, and tick Copy the setup to start from the current one.
  2. Set it up as in Set up the studio: voice sample, episode folder and Index footage, style bible, Brand kit..., house rules.
  3. In the Create tab, choose the length, shape, framing, model and options this show usually uses.
  4. Press Save as profile defaults. Every new video in this profile starts with those settings.
  5. Next time, choose the show in the Profile list. Its look, voice, footage, projects and YouTube sign-in come back at once.
  6. To back it up or move it to another PC, press Export...; on the other PC press Import... and choose the file.

An export holds the setup only: no footage, videos or sign-ins. Connections in the Settings tab are shared by every profile, except YouTube, which each profile signs in to separately. Archive... sets a profile aside without deleting it.

Top right of the window

Simple mode

  1. Tick Simple mode to show only Create, Edit recording, Highlights and Publish.
  2. Untick it when you need setup tabs such as Voice clone, Analyze, Settings or Services.

The app remembers your choice. Nothing is lost while tabs are hidden.

Settings tab · once per PC

Connect an outside service

  1. Open the Settings tab and press Check all. Each service shows connected, not connected or not checked.
  2. Press Connect on the service's row: Higgsfield and vidIQ open claude.ai's Connectors page to sign in there; Codex and Claude Code open a sign-in window; YouTube asks for the Google sign-in file once, then opens your browser; Google Drive and Riverside ask for a folder.
  3. Press Check all again to confirm it shows connected.
  4. To stop using one, press Disconnect. It is switched off in every project at once.

A service that is not connected cannot be ticked in the Services tab or chosen as the editor. The check is best effort: a connected service can still fail when used, and the work then carries on without it.

Settings tab · optional

Import a Riverside session

  1. In Riverside, download the session's separate tracks (one video per person) into one folder per session.
  2. First time only: on the Riverside exports folder row press Connect and choose the folder that holds those session folders.
  3. Press Import Riverside session... and choose one session's folder.
  4. Wait while it builds the episode (roughly as long as the session) and works out who speaks when.
  5. Use it like any episode: Highlights with Active speaker framing now cuts exactly to whoever is talking.

Handles two to four people. Each person's own track is also a clean source for the Voice clone sample.

Services tab · optional

Switch on a service for one project

  1. Choose Settings for: the Create tab project or the Edit recording project. Press Load.
  2. Tick Higgsfield, vidIQ or Google Drive. Everything starts unticked, and a service marked (not connected) cannot be ticked until you connect it in Settings.
  3. Set the credit cap for each paid service.
  4. For Google Drive, press Drive folder... and choose a folder that Google Drive for desktop syncs.
  5. Press Save for this project, or Save as my default to use the same choice for new projects.

Nothing in the app needs these. A service that is off is named as not allowed in every prompt Claude Code receives.

Services tab · optional

Use vidIQ or Higgsfield on a video

  1. Make sure the Create tab shows the right Project name and the service is switched on.
  2. Before writing the outline, press Ideas (vidIQ) for angles backed by videos that are working now.
  3. After the video is made, press Title + thumbnail (vidIQ), Music bed (vidIQ) or Dub (Higgsfield) with a language chosen.
  4. For a scene that needs better pictures, type its number in Scene and press Generated B-roll (Higgsfield).
  5. In Claude Code's window, read the quoted cost and answer yes or no.
  6. Press Open spending log to see every credit spent on this project.
  7. Press Copy to Drive folder to put the finished files in Google Drive (free, no upload by Claude).

Caps are instructions Claude follows and logs against, not limits the services enforce. Uploading to a service sends your footage to that company.

Edit recording tab · optional

Edit with Codex instead of Claude Code

  1. Install with -WithCodex, then run codex once in PowerShell and choose Sign in with ChatGPT.
  2. In Edit recording, set Editor to Codex (ChatGPT).
  3. Press 2. Edit with the editor and work in Codex's window as you would with Claude.

Codex uses your ChatGPT plan. It cannot use Higgsfield or vidIQ, which are connected to your Claude account.

Before you rely on it

The app has passed its automated tests with stand-ins for the AI models, but it has not yet run on a Windows PC. Treat the first install as a test and keep the log files it writes.

If something goes wrong

The install stops with an error
Fix what it names and run the same command again. Finished steps are skipped.
A stage fails while making a video
Press 2. Approve + make video again. Finished work is kept.
"No local chat model is installed"
Open PowerShell and run ollama pull gemma3:4b, or pick another model in the Create tab.
Out of graphics memory
Close other programs that use the GPU and untick AI stills.
A voice line sounds wrong
Scenes tab, select the scene, press Re-make this scene.
Footage shows the wrong person
Scenes tab, change the search words or press Re-make this scene for the next best moment.
